Build a production-ready, mobile-first Web Application for "SREC FC (Sri Ramakrishna Engineering College Food Court)".

### 🎨 DESIGN SYSTEM & BRAND THEME
- Color Palette: Primary Deep Forest Green (#1B4332), Background Cream (#FDFBF7), Glassmorphic Cards (`bg-white/80 backdrop-blur-md border border-white/20 shadow-sm`), Accent Emerald (#2D6A4F).
- Typography: Clean sans-serif for UI, Monospace/Courier font strictly for the Thermal Receipt.

### 📱 SCREEN-BY-SCREEN ARCHITECTURE

1. AUTHENTICATION / ONBOARDING SCREEN:
   - Full-bleed background image with a dark translucent glassmorphic overlay.
   - Branding: SREC FC logo placeholder, Title: "SREC Food Court", Subtitle: "Pre-Order & Fast Campus Pickup".
   - Input forms for Email/Password with dynamic toggle to "Sign Up" / "Log In".
   - "Continue as Student" direct entry button.

2. HOME SCREEN & DYNAMIC MENU:
   - Top Header: Local asset logo (`/assets/srec-logo.png`), Title: "Sri Ramakrishna Engineering College - Main FC", Profile Avatar icon.
   - Live Status Badge: "Live Stock Feed Active".
   - Search & Filter System:
     * Search Input: Instant case-insensitive filtering by food item name.
     * Horizontal Category Scroll Pills: "All", "Puffs & Bakery", "Breakfast", "Lunch", "Indochines", "Chats", "Snacks", "Hot Drinks", "Milkshakes", "Fresh Juice".
     * Empty Search State: If search yields 0 items, render a glassmorphic card with a search-x icon, text "No Food Items Found", subtext "Try searching for Coffee, Biriyani, or Puffs", and a "Reset Filters" button.
   - Dynamic Food Cards:
     * Displays Food Name, Price in ₹ (INR), Category tag.
     * Dynamic Stock Badge: Green "IN STOCK" (Enables "+ ADD" button) vs Red "SOLD OUT" (Grays out card, disables button).
   - Bottom Floating Navigation Bar: Home, Orders, Cart (with dynamic item count badge), Profile.

3. CART & CHECKOUT SLIDE-OVER:
   - Slide-up or dedicated page showing selected items with quantity controls (+ / -).
   - Detailed Bill Breakdown: Subtotal, 5% GST, Grand Total.
   - "Proceed to Pay" CTA button.

4. MOCK UPI PAYMENT & DIGITAL THERMAL RECEIPT (STRICT RECIEPT DESIGN):
   - Payment Selector: Simulated Google Pay, PhonePe, and Paytm UPI modal.
   - Processing timer (1.5s), routing to the Digital Thermal Receipt screen.
   - Receipt UI Specifications:
     * Stylized thermal paper container with jagged/dashed paper edges.
     * Header Logo & Text: "SREC FC - FOOD COURT", "GOOD FOOD • GREAT VIBES".
     * Metadata Table: College (SREC), Location (Food Court), Date, Time, Receipt No (Unique format: `FC` + Timestamp/Random ID e.g., `FC2509060042`), Payment Mode (UPI), Transaction ID.
     * Itemized Order Table: Column headers (No., ITEM, QTY, PRICE (₹)) with items purchased.
     * Sub Total, GST (5%), Grand Total.
     * Footer: "Thank you for dining with us! SREC FC - EAT • RELAX • REPEAT".
     * Dynamic Barcode Engine: Render a 1D barcode encoding the exact unique Receipt Number.
     * Status Badge: Green tag showing "STATUS: PAID & VERIFIED".

5. PROFILE, HISTORY & EDIT USER DETAILS:
   - Profile card displaying User Name, Student Roll Number, and Avatar.
   - Edit Profile Modal: Update Name, Phone Number, and Roll Number with localStorage persistence.
   - Recent Purchase History List: Shows past order cards. Clicking any past order opens its unique generated barcode receipt.
   - Toggle Setting: "Enable Daily Lunch Reminders (12:00 PM)".
   - Logout button returning to Auth Screen.

6. ADMIN LIVE FEED TOGGLE (FOR DEMO PRESENTATION):
   - In Settings/Profile, include a switch titled "Admin Stock Management Mode".
   - When active, clicking on any food card on the main menu toggles its state instantly between "IN STOCK" and "SOLD OUT" to demonstrate live data feeds to judges.
